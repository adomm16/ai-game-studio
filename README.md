# AI Game Studio Operating System v0.1

Marka, oyun ve motor kararı vermeden kurumsal karar, araştırma, üretim ve denetim altyapısı sağlar.

## Başlangıç

1. [AGENTS.md](AGENTS.md) dosyasını okuyun.
2. [Dokümantasyon haritasını](docs/index.md) açın.
3. Doğrulama çalıştırın: `python scripts/validate_studio.py`
4. Testleri çalıştırın: `python -m unittest discover -s tests -v`

Bu sürüm oyun kodu, marka adı, oyun adı, görsel varlık veya ticari karar içermez.
