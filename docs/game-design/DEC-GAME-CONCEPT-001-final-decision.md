# DEC-GAME-CONCEPT-001 — Final Concept Decision

## Decision

Founder selected **CONCEPT-B — Ashfall Provinces** as the game concept to advance into an Unreal Engine vertical slice.

## Authority

- Decision owner: Founder
- Decision date: 2026-08-11
- Status: APPROVED
- Source options: `docs/game-design/game-concept-options.md`

## Approved direction

The first implementation will test the relationship between settlement households, productive labor, army formation, casualties and lasting economic consequences. It will use Unreal Engine 5.8 with a C++ gameplay core. Blueprint and UI layers may be added later.

## Scope boundary

This decision authorizes the bounded single-player vertical-slice foundation described in `ashfall-provinces-vertical-slice.md`. It does not authorize multiplayer, MMO services, monetization, public release or expansion beyond that slice.
