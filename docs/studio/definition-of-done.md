# Definition of Done

Teslim; kapsam, sahip, kabul kriteri, kaynaklar, varsayımlar, riskler, bağımsız inceleme, gerekli onaylar, test sonuçları ve handoff içerdiğinde tamamdır. Kritik belgeler boş olamaz; validator ve testler geçmelidir. Kurucuya ayrılmış kararlar yazılı onaysız tamamlanmış sayılamaz.
