# Kurucunun Korunmuş Yetkileri

Yalnızca kurucu aşağıdaki işlemleri onaylayabilir:

- Stüdyo adı
- Şirket kuruluşu
- Marka tescili başvurusu
- Alan adı satın alma
- Ana oyun projesinin seçimi
- Oyun adı
- Bütçe ve ücretli servis kullanımı
- Yatırımcı veya yayıncı anlaşmaları
- Personel veya yüklenici sözleşmeleri
- Public release
- Main branch korumalarının kaldırılması
- Büyük kapsam değişiklikleri
- Canlı para kazanma sistemi
- Oyuncu verisi toplayan sistemlerin açılması

Agentlar yalnızca seçenek ve kanıt sunar; sessizlik onay sayılmaz.
