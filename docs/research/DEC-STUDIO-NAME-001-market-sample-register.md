# DEC-STUDIO-NAME-001 Market Sample Register

## Scope and status

This register is a factual, purposive and stratified market sample as of `2026-08-08`. It is not a market census, brand recommendation, legal conclusion, or final approval. The canonical row-level data is `DEC-STUDIO-NAME-001-market-sample-register.csv`; this Markdown file records controls and totals. Independent Market Research audit is required.

## Counting controls

- Counted Sample IDs: **200**, all unique.
- Active game/publisher records: **150**; adjacent active technology/creative brands: **30**; historical events: **20**.
- Each row has exactly one primary layer and two Source IDs. No secondary tag increases a quota.
- All 180 active records contain two distinct activity-signal fields and at least one organisation-controlled/direct platform source. Source content review remains `UNREVIEWED`; this package does not self-approve.
- Historical events use an Event ID and are not silently counted as active entities.

## Data dictionary and limitations

The CSV carries the framework-required identities, layer, status, region, scale criterion, activity evidence, source allocation, confidence and reviewer fields. Foundation year, employee count and detailed ownership were not populated where the first-pass official pages did not expose consistent data; no estimate is presented as fact. `NOT VERIFIED` is preserved rather than inferred. All URLs are changeable snapshots and require recheck on `2026-08-15` and before proposal use.
